# Password Changer

A professional, lightweight, and modern Windows tool to change the current user's credentials instantly without knowing their old password. 

Now updated with a secure dual-panel wizard interface, background stealth execution, and high-fidelity UI/UX styling.

### 🆕 What's New in the Latest Version
- **Dual-Panel Wizard Flow:** Separates the entry and validation into a polished multi-step screen setup.
- **Stealth Background Execution:** Automatically auto-forks on launch to completely suppress and hide the ugly background blue PowerShell console window.
- **Dynamic Character Masking:** Fully hides passwords while typing with an option to toggle character visibility via a flat-styled checkbox.
- **Confirmation Verification:** Eliminates typing mistakes by requiring a matching duplicate confirmation pass-phrase before modifying system access.
- **1-Character Pin Support:** Retains core compatibility natively allowing custom 1-character entries or full pass-phrases with zero artificial length limits.
- **Intelligent Focus Routing:** Seamlessly auto-focuses input cursors on step transitions and resets confirmation blocks gracefully on validation mismatches.
- **Startup Integrity Pathing:** Auto-detects if launched natively inside the Windows Startup routine folder to calibrate safe system execution environments seamlessly.

### Features
- **Ultra-Lightweight:** Just about 0.2MB in storage imprint.
- **Modern Fluent UI/UX:** Built with a custom clean off-white palette, smooth flat components, high contrast typography, and premium corporate padding footprints.
- **Admin-Level Execution Safeguards:** Wraps low-level native processes cleanly with comprehensive structural `.NET` exception tracing.
- **Zero Configuration:** Drop it anywhere, execute instantly, single file layout.

### How to Use
1. Download `PasswordChanger.exe` (or run the underlying script file directly).
2. Launch the tool.
3. Click **Yes** if standard User Account Control (UAC) privileges prompt for runtime access.
4. **Step 1:** Enter your desired password structural payload and click **Next Step**.
5. **Step 2:** Verify your sequence by re-typing it into the confirmation field and click **Update System Entry**.
