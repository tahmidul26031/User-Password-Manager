# Password Changer

A simple Windows tool to change or remove the current user's password.

### Features
- Clean graphical interface
- Change password or completely remove it
- Runs with Administrator rights
- Lightweight

### How to use
1. Download `PasswordChanger.exe`
2. Double-click the file
3. Click **Yes** when Windows asks for permission
4. Type a new password (or leave it empty to remove the password)
5. Click **Apply**

### Notes
- Works only with local Windows accounts
- Source code is included

### Disclaimer
Use responsibly. Removing a password makes your account less secure.
